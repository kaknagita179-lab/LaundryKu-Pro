# LaundryKu Pro Professional

Fitur:
- Login PIN admin (default 1234)
- Dashboard transaksi, status, dan pendapatan
- Tambah transaksi dan kalkulasi harga/kg
- Riwayat + pencarian
- Data pelanggan
- Laporan berdasarkan rentang tanggal
- Nota dan kirim melalui WhatsApp
- Pengaturan nama usaha, tagline, dan PIN
- Penyimpanan offline di perangkat (localStorage)

Build APK:
1. Buka folder ini dengan Android Studio.
2. Tunggu Gradle sync.
3. Pilih Build > Build APK(s).
4. APK debug biasanya muncul di app/build/outputs/apk/debug/.

Catatan: proyek ini tidak menyertakan Android SDK/Gradle wrapper sehingga APK final perlu di-build di Android Studio.
